# Alt.Point Mobile Test Task

Тестовое задание — приложение доставки еды на Flutter.

## Что реализовано
- 4 экрана: главный со списком блюд, фильтр по категориям, детальная страница блюда, боковое меню (Drawer)
- Поиск по названию
- Фильтрация по категориям (Все / Пицца / Кебаб / Бургер)
- Состояние избранного на детальной странице
- Табы "Дополнительно / Похожие / Отзывы"
- Список доп. товаров на вкладке "Дополнительно"

## Стек
- Flutter 3.x
- Dart
- Material Design

## Структура проекта
```
lib/
├── main.dart                  — точка входа
├── models/
│   └── dish.dart              — модель блюда
├── data/
│   └── mock_data.dart         — тестовые данные
├── theme/
│   └── app_colors.dart        — цвета приложения
├── widgets/
│   ├── dish_card.dart         — карточка блюда в списке
│   ├── category_selector.dart — селектор категорий
│   └── app_drawer.dart        — боковое меню
└── screens/
    ├── home_screen.dart       — главный экран
    └── dish_detail_screen.dart — экран блюда
```

## Запуск

```bash
flutter pub get
flutter run -d chrome
```

## Ассеты
Картинки блюд экспортированы из макета Figma и лежат в `assets/images/`.
